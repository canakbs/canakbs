It gives personalized career advice based on the user's skills and goals.
`Python` `Gemini API` `Pinecone` `RAG`

### 📊 Excel Pro Analyzer *(in progress)*
An AI-powered BI tool that reads Excel files, generates charts, and makes predictions using **TabFPN**.

`Python` `Transformers` `NLP`
