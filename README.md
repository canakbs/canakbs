## Featured Projects

### 👁️ [Eyeputer — Gaze-Tracking Accessibility App](https://github.com/canakbs/Eyeputer)
A fully offline Windows app that lets people control their computer using only eye movements and blinks.
Built with MediaPipe iris tracking, a 9-point calibration system, Kalman filter smoothing, and a PyQt6 UI.
No external dependencies — runs entirely on your local webcam.
`Python` `MediaPipe` `OpenCV` `PyQt6` `Kalman Filter` `Computer Vision`

### 🔍 [Career Guide Chatbot](https://github.com/canakbs/career-guide-chat-bot)
A web-based chatbot built on **RAG architecture** using Gemini API and Pinecone vector database.
Gives personalized career advice based on the user's skills and goals.
`Python` `Gemini API` `Pinecone` `RAG` `Flask`

### 📊 Excel Pro Analyzer *(in progress)*
An AI-powered BI tool that reads uploaded Excel files, generates charts, and makes predictions using **TabFPN**.
`TypeScript` `OpenAI API` `TabFPN` `React`

### 🧠 [NLP with Deep Learning](https://github.com/canakbs/NLP-with-Deep-Learning)
Hands-on implementations of RNN, LSTM, GPT, LLaMA, Gemini API, and AI Agents — built while studying NLP and LLM architectures.
